# Root r14n Document

This document adds the global defaults for all r14n regulatory-policy-pack documents. When a document declares `extends: "r14n@1.0.0"` in its front matter, this document is prepended — authors then write ONLY what is specific to their pack. Every field listed here is a default an author does NOT need to write.

This is the r14n equivalent of `TAXA.n` / `RACONTEUR.n` (the framework global-defaults documents). The same principle applies: the framework reduces the N Lang an author must write to the minimum specific to their domain. A minimal r14n pack with all defaults accepted is a handful of very readable lines.

> **NOT LEGAL ADVICE** (r14n `GOVERNANCE.md` governing constraint). r14n maps `(regulatory-profile × jurisdiction × subject) → required compliance controls`. Its output is a control-prescription, resolved **fail-closed**, never a statement of law. Real-jurisdiction packs are counsel-gated and held out; only Squillo's own `aggressive` / `minimal` baselines ship in this framework.

## r14n Front Matter Extension

Defining a new local variable `@r14n` that is a string type — the parser version pin.

```nlang
blocks "@r14n" {
  front_matter = true
  atom         = str
  format       = "sem_ver"
  description  = "Front Matter Extension to specify the version of r14n that was used"
  examples     = ["1.0.0"]
}
```

## Default Strictness

The default strictness dial for all r14n packs. Authors override only when a pack relaxes below the fail-closed floor.

**Why `aggressive`:** r14n resolves **fail-closed** (`GOVERNANCE.md`). The install default requires the caller's FULL declared control universe regardless of the subject table; the resolver degrades to exactly this posture when no pack matches. A pack that omits `strictness` inherits this floor.

```nlang
default_strictness {
  strictness = "aggressive"
}
```

---

## Default Legal-Review Status

The default counsel-review status for a pack that omits `legal_review_status`.

**Why `not_required`:** Squillo's own `aggressive` baseline requires MORE than any jurisdiction would — no counsel sign-off is needed to be over-restrictive. A pack that RELAXES (a `minimal` profile) SHOULD set `requires_signoff` so the relaxation is visibly counsel-gated.

```nlang
default_legal_review {
  legal_review_status = "not_required"
}
```

## Control Vocabulary

Control keys are **opaque** — the enforcing gate (`RegulatoryPolicyPort` in the consuming OS) owns their polarity. A pack only declares WHICH keys a subject requires; the framework does not define what a key means. This keeps the pack a pure control-prescription (RLPS `spec/RLPS-v0.1.md`) rather than an enforcement mechanism.
