# r14n Specification — Module Index

Deterministic declaration index for the r14n Specification Snapp root.
Per the N Language Book, `1. Introduction/1. Introduction.md` §1.1 "The Determinism Invariant":
`lib.n.md` / `mod.n.md` declaration order IS the file load order; undeclared
sibling files never load. This file replaces glob()-based discovery for the
r14n Snapp (mirrors the Taxa / Raconteur / Nimble gold-standard root index).
